⚠️ Problema Mais Comum: Regras do Firebase

Se você vê produtos no admin mas NÃO no catálogo, provavelmente as regras não estão configuradas!

  1. Acesse: Firebase Console
  2. Vá em Realtime Database → Regras
  3. Cole este código:
{
"rules": {
"produtos": {
".read": true,
".write": "auth != null"
}
}
}
  1. IMPORTANTE: Clique em PUBLICAR (não basta só colar!)
  2. Volte aqui e clique em "🔄 Testar Novamente"
